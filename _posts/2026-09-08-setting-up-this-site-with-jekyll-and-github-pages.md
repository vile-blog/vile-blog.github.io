## Why Jekyll + GitHub Pages

- Free hosting directly from a GitHub repo
- No build step required locally — GitHub builds the site for you on push
- Write posts in plain Markdown, no CMS needed

## Structure

```
_layouts/    -> page templates
_includes/   -> reusable partials (nav, hero, footer, etc.)
_posts/      -> blog posts (this file!)
_data/       -> structured data, e.g. projects.yml
assets/      -> css, js
```
